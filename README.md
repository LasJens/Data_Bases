# Database Course Project

This repository contains my coursework and project materials for the **Database** course. It includes practical SQL tasks, database models, and a full project implementation.

## Project Structure

### Folders (Tasks)

- **Индексы** — tasks on database indexes
- **Представления** — tasks on SQL views
- **Простые запросы** — simple SQL query exercises
- **Триггеры** — tasks on database triggers
- **Функции Процедуры** — tasks on functions and stored procedures

### Files

- **Concept Model.png** — conceptual data model (ER diagram)
- **Logic Model.png** — logical data model
- **DDL.sql** — SQL script for defining the database schema
- **DML.sql** — SQL script with data manipulation operations
- **phys_model_bd.xlsx** — physical data model in spreadsheet format
- **concept.drawio** — source file for the conceptual model (draw.io)
- **logic.drawio** — source file for the logical model (draw.io)

## Technologies

- SQL
- PostgreSQL
- draw.io (for ER diagrams)

## Purpose

The repository serves as an archive of my database coursework and the final project, including both the theoretical models and their SQL implementation.
